- 站点级元数据统一从 `@/config/site` 的 `siteConfig` 读取（url/name/description/ogImage 等），避免硬编码字符串。
- SEO 相关配置（Open Graph、Twitter Card、robots、verification、icons）集中在根布局的 `metadata` 对象中声明，而非分散在各页面。
- 主题切换通过 CSS 变量 + Tailwind 的 `@theme inline` 暴露设计令牌，并在 `@layer base` 中以类名选择器（`:root`、`.dark` 等）覆盖同一组变量实现多主题。
- 外部脚本（Google Analytics、Convot Widget）通过 `next/script` 或 `@next/third-parties` 按需注入，并使用 `process.env.NEXT_PUBLIC_*` 条件化渲染以避免空值。
- Sitemap 采用静态路由数组与动态博客列表拼接的模式，所有 URL 均以 `siteConfig.url` 为前缀构造。
