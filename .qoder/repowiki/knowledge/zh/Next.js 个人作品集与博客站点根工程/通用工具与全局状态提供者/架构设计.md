模块按职责分为三层：`hooks/` 存放自定义 Hook（`use-lock-body.ts` 通过 `useLayoutEffect` 锁定页面滚动；`use-modal-store.ts` 基于 Zustand 创建跨组件共享的模态 store）；`lib/` 提供无副作用的工具函数（`utils.ts` 暴露 `cn` 合并 Tailwind class 与日期格式化；`blogs.ts` 通过 `gray-matter` + `remark` 读取 `content/blogs` 下的 Markdown 文件并输出元数据与 HTML）；`providers/` 为 Next.js 客户端组件包装器（`modal-provider.tsx` 使用 `useState`+`useEffect` 避免 SSR 水合差异后挂载 `CustomModal`，`animation-provider.tsx` 作为预留的动画上下文占位）。依赖方向单向：providers 可消费 hooks/lib，hooks 不依赖 providers，lib 仅依赖 Node fs 与第三方库，整体构成应用的基础能力层。
