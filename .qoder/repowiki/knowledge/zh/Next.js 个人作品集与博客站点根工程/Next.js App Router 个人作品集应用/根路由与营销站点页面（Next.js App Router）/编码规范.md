- 每个页面文件导出 `metadata: Metadata` 对象，集中声明 title、description、canonical、OpenGraph 与 Twitter Card 等 SEO 元信息。
- 动态路由页面通过 `generateStaticParams` 配合 `get*` 数据函数预生成路由参数，并在渲染失败时调用 `notFound()`。
- 列表/详情页统一通过 `Script` 组件注入 schema.org JSON-LD（如 BlogPosting、CollectionPage、BreadcrumbList、Person），并以 `id` 区分多个结构化数据块。
- 页面内容使用 `AnimatedSection` / `AnimatedText` 包裹，配合 `delay` 与 `direction="up"` 实现滚动入场动画。
- 页面文本标题与描述统一从 `@/config/pages` 的 `pagesConfig` 读取，避免硬编码文案。
- 可复用页面骨架通过 `PageContainer`（列表页）或 `ClientPageWrapper`（首页/详情）封装，保持布局一致性。
