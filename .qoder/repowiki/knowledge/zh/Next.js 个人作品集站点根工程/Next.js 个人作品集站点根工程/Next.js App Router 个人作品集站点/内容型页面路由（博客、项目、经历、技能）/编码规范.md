- 列表页统一从 `@/config/pages` 读取 `title` / `description` / `metadata` 并挂载到 `export const metadata`，再传入 `PageContainer` 作为页面头部。
- 动态详情页使用 `params: Promise<{...}>` 解构路由参数，并在找不到资源时调用 `notFound()`（博客）或 `redirect('/xxx')`（项目、经历）进行错误处理。
- SEO 通过双通道实现：`export const metadata` 设置 OpenGraph/Twitter 卡片，同时用 `next/script` 注入 `application/ld+json` 的 `BlogPosting` / `CollectionPage` / `BreadcrumbList`。
- 可交互或需要客户端能力的页面（博客详情、经历详情）以 `ClientPageWrapper` 包裹，内部再嵌套 `AnimatedSection` / `AnimatedText` 实现入场动画。
- 多段内容展示统一使用 `ResponsiveTabs` 组件，并以 `{ value, label, content }` 数组形式声明 Tab 项，默认选中第一项。
- 外部链接统一使用 `target="_blank" rel="noopener noreferrer"`，并通过 `Icons.*` 图标组件替代内联 SVG。
