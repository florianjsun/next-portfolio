模块以单文件一组件的方式组织，每个 `.tsx`/`.ts` 暴露一组语义化命名的 React 组件或 Hook，作为上层业务页面直接引用的 UI 基座。
- 基础样式与主题：通过 `@/lib/utils` 的 `cn` 工具合并 className，并使用 Tailwind 语义化颜色（如 `bg-primary`、`text-destructive`）统一视觉风格。
- 无头 UI 层：大量组件是对 Radix UI 原语的薄封装（`dialog.tsx`、`toast.tsx`、`dropdown-menu.tsx`、`tooltip.tsx`、`custom-tooltip.tsx`），仅添加默认样式与组合逻辑，保持可访问性与行为由 Radix 提供。
- 变体系统：使用 `class-variance-authority` 的 `cva` 定义 variant/size 等变体（如 `button.tsx`、`toast.tsx`），并通过 `VariantProps` 推导类型。
- 复合组件模式：`form.tsx` 通过多个 Context（`FormFieldContext`、`FormItemContext`）配合 `react-hook-form` 的 `Controller` 实现 Form/FormItem/FormControl/FormLabel/FormMessage 的组合式 API；`dialog.tsx` 将 Root/Trigger/Content/Overlay/Header/Footer/Title/Description 拆分为独立导出组件。
- 全局状态管理：`use-toast.ts` 用 reducer + listeners 数组实现进程内 toast 状态机（ADD/UPDATE/DISMISS/REMOVE），`toaster.tsx` 消费该状态渲染容器，`toast.tsx` 提供带样式的 Toast 子组件。
- 组合型高级组件：`responsive-tabs.tsx` 在移动端回退为 `DropdownMenu`+`Button`，桌面端使用 `Tabs`，体现按断点切换布局的策略；`chip-container.tsx` 与 `chip.tsx` 构成标签容器与标签项。
- 依赖方向：本模块仅向下依赖 `@/lib/utils`、`@radix-ui/*`、`lucide-react`、`react-hook-form`，不反向被其他 UI 组件引用，是纯叶子组件层。
