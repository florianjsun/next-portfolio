- 枚举式字段统一在 `constants.ts` 中以 TypeScript 联合类型（如 `ValidSkills`、`ValidCategory`、`ValidExpType`、`ValidPages`）声明并跨文件复用。
- 每个业务数据模块采用「接口定义 + 未排序数组 + featured 切片」模式，例如 `experiences`/`Projects`/`contributionsUnsorted` 配合 `featuredExperiences`/`featuredProjects`/`featuredContributions`。
- 页面配置通过以 `ValidPages` 为键的映射对象组织，新增页面需同时更新 `constants.ts` 中的 `ValidPages` 联合类型以保持编译期校验。
- 对外暴露的数据均为顶层 `export const` 常量对象或数组，不包含函数或类，保证配置可被任意组件直接 import 使用。
- 图标资源统一从 `@/components/common/icons` 的 `Icons` 命名空间引入，而非内联 SVG 或字符串路径。
