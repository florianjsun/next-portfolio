- ui 层组件统一使用 `React.forwardRef` 转发 ref，并通过 `cva` 定义 variant/size 等样式变体，默认导出组件及 variants 函数。
- className 合并一律通过 `cn(...)` 工具函数完成，避免字符串拼接。
- 业务组件以目录分组（projects、experience、skills 等），每个目录内按功能拆分文件并以 default export 暴露主组件。
- 跨组件全局状态通过 `zustand` 的 `create` 创建 store（如 use-modal-store），并由对应 Provider 挂载到应用顶层。
- 需要客户端能力的组件/Provider 在文件顶部声明 `'use client'` 指令以支持动态特性。
- 图标集中聚合于 `components/common/icons.tsx`，从 lucide-react 与 react-icons 等多来源导入后统一以命名对象形式导出供业务组件消费。
