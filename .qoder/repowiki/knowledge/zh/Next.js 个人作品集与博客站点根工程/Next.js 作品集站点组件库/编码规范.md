- 所有业务与通用组件均以 `.tsx` 文件形式暴露单一默认导出，便于按需 import。
- UI 原语使用 class-variance-authority 定义 variant/size 等变体，并通过 className 合并策略对外暴露。
- 需要浏览器 API 或状态管理的组件统一以 `'use client'` 指令声明为客户端组件。
- 动画效果统一通过 Framer Motion 的 `motion` 组件与 `useInView` / `AnimatePresence` 实现，避免内联 keyframe。
- 主题色与尺寸等设计令牌通过 Tailwind 配置集中管理，组件内部仅消费语义化类名而非硬编码值。
