模块按功能划分为四个并列的 Next.js 路由组：`blogs/`、`projects/`、`experience/`、`skills/`，均位于 `app/(root)/` 下共享根布局。
- 列表页（`page.tsx`）统一通过 `PageContainer` 包裹标题与描述，并从 `@/config/pages` 读取 SEO 元信息；数据源来自对应 `@/config/*` 或 `@/lib/blogs` 中的静态配置/Markdown 解析。
- 详情页采用动态路由 `[slug]` / `[projectId]` / `[expId]`，通过 `generateStaticParams`（博客）或运行时查找 + `redirect`（项目、经历）实现参数化渲染；不存在时分别调用 `notFound()` 或 `redirect` 回退到列表页。
- 每个详情页都通过 `next/script` 注入 JSON-LD（`BlogPosting`、`CollectionPage`、`BreadcrumbList`）并配合 `Metadata` 导出完成 SEO；博客列表还额外输出站点级 BreadcrumbSchema。
- UI 层复用通用组件：`AnimatedSection` / `AnimatedText` 提供滚动动画，`ClientPageWrapper` 包裹客户端交互区域，`ResponsiveTabs` 用于项目/经历的标签式内容组织，图标统一来自 `@/components/common/icons`。
- 依赖方向单向向外：页面 → `@/config/*`（数据）→ `@/components/*`（UI），不反向引用其他路由。
