本模块由三个并列的 React 子目录组成，每个子目录对应一类内容展示卡片：`blogs/blog-card.tsx` 接收 `BlogMeta` 数据渲染带封面图、标签、阅读时长和日期的文章卡片；`contributions/contribution-card.tsx` 基于 `@/config/contributions` 中的 `contributionsInterface` 数组渲染外部链接的项目卡片；`contact/github-redirect-card.tsx` 使用 `"use client"` 客户端组件模式配合 `useState` 实现悬停动效并跳转到模板源码仓库。三者均通过 `@/components/common/icons` 统一图标、遵循 Next.js App Router 的组件约定，并以 `export default` 暴露默认组件供上层页面组合使用，不引入业务逻辑，仅负责数据到视图的呈现。
