模块按职责划分为三层：`components/ui/` 存放原子级无样式基础组件（Button、Card、Dialog、Tabs、Tooltip 等），统一通过 `class-variance-authority` 定义 variant/size 变体，并使用 `@/lib/utils` 的 `cn` 合并 className；`components/{common,projects,experience,skills,blogs,contact,contributions,forms,modals,backgrounds}` 为业务页面级组合组件，依赖 ui 层并消费 `@/config/*` 数据模型；`hooks/` 暴露跨组件状态（如 `use-modal-store` 基于 Zustand）与 DOM 副作用（如 `use-lock-body` 锁定滚动）；`providers/` 暴露应用级 Provider（`ModalProvider` 挂载 `CustomModal`，`ThemeProvider` 封装 next-themes）。依赖方向自下而上：业务组件 → ui 组件 → 第三方库（Radix、next-themes、zustand、lucide-react），Provider/Hook 作为横向横切能力被上层消费。所有客户端组件显式标注 `'use client'` 以支持动态特性。
