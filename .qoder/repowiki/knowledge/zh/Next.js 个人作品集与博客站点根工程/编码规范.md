- 所有跨模块导入使用 @/* 路径别名（由 tsconfig.json 定义），禁止相对路径穿越层级引用
- UI 组件通过 shadcn/ui 的 components/utils 别名（@/components、@/lib/utils）引入，样式基于 Tailwind CSS v4 与 CSS 变量
- 站点元数据、路由与静态内容集中在 configuration 模块，页面与 API 通过 import 直接消费而非运行时读取
- 博客文章以 Markdown + YAML front matter 形式存放在 blog_content，由 utilities 中的 remark 解析管线统一渲染
