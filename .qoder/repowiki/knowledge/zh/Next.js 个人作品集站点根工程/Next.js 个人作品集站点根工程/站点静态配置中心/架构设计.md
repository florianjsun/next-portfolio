本模块以纯 TypeScript 配置文件形式作为整个站点的单一数据源，按领域拆分为独立文件：`site.ts` 定义站点级元信息（名称、描述、SEO 关键词、OG 图片、外链），`routes.ts` 提供主导航菜单数组并导出 `RoutesConfig` 接口，`pages.ts` 通过 `ValidPages` 字面量联合类型约束每个页面的 title/description/metadata；`projects.ts`、`experience.ts`、`skills.ts`、`contributions.ts`、`socials.ts` 分别维护对应实体数组并导出 `featured*` 切片供首页展示；`constants.ts` 集中声明跨文件共享的枚举式联合类型（`ValidSkills`、`ValidCategory`、`ValidExpType`、`ValidPages`）。依赖方向单向：业务配置 → `constants`，不反向引用组件或页面逻辑，仅通过相对路径引入 `@/components/common/icons` 中的图标引用，使该模块可被任意页面按需导入而不引入 UI 渲染开销。
