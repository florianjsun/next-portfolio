模块按主题划分为两个并列子目录：`experience/` 包含 `ExperienceCard`（单条经历卡片）和 `Timeline`（按结束时间倒序排列的经历列表，并包裹 `AnimatedSection` 实现滚动入场动画）；`skills/` 包含 `SkillsCard`（网格布局的技能卡片集合）与 `Rating`（基于 SVG 的五星评分）。所有组件均为 React 函数组件，通过 props 接收数据，依赖方向单向指向共享层：类型定义来自 `@/config/experience` 与 `@/config/skills`，UI 基础控件来自 `@/components/ui/button`，图标来自 `@/components/common/icons`，动画由 `@/components/common/animated-section` 提供。组件之间无相互调用，仅 `SkillsCard` 组合 `Rating`，整体为纯展示型叶子组件。
