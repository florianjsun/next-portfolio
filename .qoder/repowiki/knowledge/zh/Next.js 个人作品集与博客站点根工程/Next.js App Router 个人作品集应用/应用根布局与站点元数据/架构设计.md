本模块由四个位于 `app/` 目录的顶层文件组成，分别承担 Next.js 应用的不同根级职责：
- `layout.tsx` 作为根布局组件，通过 `metadata` 对象集中声明站点标题模板、Open Graph/Twitter 卡片、robots、canonical、icons、manifest 等 SEO 元信息，并在渲染树中包裹 `ThemeProvider`（支持 light/dark/retro/cyberpunk/paper/aurora/synthwave 七种主题）、`Analytics`、`Toaster`、`ModalProvider`，同时注入 Google Analytics 与第三方 Convot 聊天脚本。
- `globals.css` 基于 Tailwind CSS v4（`@import "tailwindcss"`）与 `tw-animate-css`，通过 `@theme inline` 暴露设计令牌（颜色、圆角、字体），在 `@layer base` 下定义 `:root`、`.dark`、`.retro`、`.cyberpunk`、`.aurora`、`.synthwave`、`.paper` 等多套 CSS 变量主题，并包含博客 Markdown 内容（`.blog-content`）的排版样式。
- `manifest.ts` 导出符合 `MetadataRoute.Manifest` 类型的 PWA 清单，声明名称、图标、显示模式与分类。
- `sitemap.ts` 导出 `MetadataRoute.Sitemap`，静态列出主页、skills/projects/experience/contributions/blogs/contact/resume 等路由，并通过 `getAllBlogsMeta()` 动态追加每篇博客条目。
依赖方向单向向下：布局与 sitemap 均从 `@/config/site` 读取站点配置，不反向被业务页面引用；CSS 仅通过 `@import` 引入框架层，无 JS 耦合。
