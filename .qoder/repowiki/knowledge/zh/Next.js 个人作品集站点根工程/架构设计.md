以 `app/` 作为 Next.js App Router 唯一入口（根 `layout.tsx` + `(root)/` 路由组承载所有页面），各业务域通过目录划分；`components/` 按业务域（blogs/projects/experience/skills 等）与通用层（common/ui/forms/modals/backgrounds）分层复用，UI 原语集中在 `components/ui`；`config/` 集中管理站点常量、项目、经验、技能、社交链接等静态数据，被页面与组件直接导入；`lib/` 提供跨模块工具（Markdown 解析、GitHub 贡献抓取、Notion Webhook 处理、URL/JSON-LD 生成），由 `app/api/` 下的 Server Route 与客户端组件共同消费；`providers/` 与 `hooks/` 暴露全局状态（模态框 Zustand store、主题 Provider），在根布局中一次性注入；`public/` 与 `assets/fonts/` 作为静态资源供全仓引用。整体无多进程或微服务边界，依赖通过 Node 模块解析与相对路径组织。
