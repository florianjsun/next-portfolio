- 每个子目录只包含一个以内容命名的卡片组件文件，并通过 `export default` 导出默认组件。
- 组件 props 通过独立的 TypeScript interface 定义（如 `BlogCardProps`、`ContributionCardProps`），并在解构参数中直接使用。
- 外部链接统一使用 Next.js 的 `Link` 组件包裹卡片根元素，对站外链接添加 `target="_blank"`。
- 图标统一从 `@/components/common/icons` 导入并使用，避免直接依赖第三方图标库。
- 文本截断使用 Tailwind 的 `line-clamp-*` 类控制多行省略，保持卡片布局稳定。
