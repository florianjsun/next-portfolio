- 所有枚举式字段使用 TypeScript 联合类型（如 `ValidSkills`、`ValidCategory`、`ValidExpType`、`ValidPages`）在 `constants.ts` 中统一定义并跨文件复用。
- 每个数据模块采用「接口定义 + 未排序数组 + featured 切片」的模式，例如 `skillsUnsorted`/`skills`/`featuredSkills`、`contributionsUnsorted`/`featuredContributions`、`Projects`/`featuredProjects`。
- 页面配置通过映射键（keyed by `ValidPages`）组织，新增页面需同时更新 `constants.ts` 中的 `ValidPages` 联合类型以保持类型安全。
- 图标资源统一从 `@/components/common/icons` 的 `Icons` 命名空间引入，而非内联 SVG 或字符串路径。
- 对外暴露的数据均为顶层 `export const` 常量，不包含函数或类，保证配置可被任意组件直接 import 使用。
