根目录作为唯一 Next.js 应用入口（package.json scripts 暴露 dev/build/start/lint），通过 next.config.js 为 /api/sb-contact 设置 CORS 头；tsconfig.json 启用 @/* 路径别名并开启 strict + isolatedModules，使 app/ 下的 pages_and_routes、shared_components、configuration 以及 blog_content 四个子模块在同一编译单元内互相引用。运行时，pages_and_routes 消费 configuration 中的站点元数据与路由表，渲染 shared_components 提供的基于 Radix UI 的原子与业务组件，并通过 remark/gray-matter 管线读取 blog_content 的 Markdown 文章生成页面；pnpm-workspace.yaml 仅用于兼容 unrs-resolver 与 ESLint 10 的 peerDependency，实际并非多包工作区。
