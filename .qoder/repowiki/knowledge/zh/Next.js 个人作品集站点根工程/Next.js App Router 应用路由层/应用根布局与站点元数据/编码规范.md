- 站点元信息统一从 `@/config/site` 导入的 `siteConfig` 读取，避免硬编码 URL、名称、描述、OG 图片等值。
- SEO 相关元数据（title 模板、Open Graph、Twitter card、robots、icons、manifest、alternates canonical）集中在根布局的 `metadata` 对象中声明。
- 多主题通过 CSS 变量（`--background`、`--foreground`、`--primary` 等）在 `:root` 与各主题类（`.dark`、`.retro`、`.cyberpunk`、`.aurora`、`.synthwave`、`.paper`）中成对定义，并由 `ThemeProvider` 以 class attribute 方式切换。
- 字体通过 `next/font` 加载并以 CSS 变量（`--font-inter`、`--font-cal-sans`）暴露给 Tailwind 的 `--font-sans` / `--font-heading` 使用。
- sitemap 条目统一包含 `url`、`lastModified`、`changeFrequency`、`priority` 四字段，并按页面重要性分级设置 priority。
