模块按功能划分为四个并列的 Next.js 路由组 `blogs/`、`projects/`、`experience/`、`skills/`，均位于共享根布局 `(root)/` 下：
- 列表页（各目录下的 `page.tsx`）统一通过 `PageContainer` 包裹标题与描述，并从 `@/config/pages` 读取 SEO 元信息；数据源来自对应 `@/config/*`（projects/experience/skills）或 `@/lib/blogs` 中的 Markdown 解析。
- 详情页采用动态路由 `[slug]` / `[projectId]` / `[expId]`：博客通过 `generateStaticParams` + `notFound()` 处理缺失项；项目与经历通过运行时查找失败后 `redirect('/xxx')` 回退到列表页。
- SEO 双通道：`export const metadata` 设置 OpenGraph/Twitter 卡片与 canonical URL，同时用 `<script type="application/ld+json">` 注入 `BlogPosting`、`CollectionPage`、`BreadcrumbList` 等 Schema.org 结构化数据，由 `@/lib/json-ld` 的 `serializeJsonLd` 序列化。
- UI 层复用通用组件：`AnimatedSection` / `AnimatedText` 提供滚动入场动画，`ClientPageWrapper` 包裹客户端交互区域，`ResponsiveTabs` 用于项目/经历的标签式内容组织，图标统一来自 `@/components/common/icons`。
- 依赖方向单向向外：页面 → `@/config/*`（数据）→ `@/components/*`（UI），不反向引用其他路由。
