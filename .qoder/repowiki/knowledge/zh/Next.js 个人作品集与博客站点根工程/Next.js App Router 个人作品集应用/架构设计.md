本模块以 `app/` 作为 Next.js App Router 根目录，通过文件系统约定将三个层次解耦：顶层 `layout.tsx`、`globals.css`、`manifest.ts`、`sitemap.ts` 提供全局壳（字体、主题、SEO、PWA）；`(root)/` 路由组承载所有面向用户的营销页面，使用 `[slug]`、`[expId]`、`[projectId]` 等动态段渲染博客、项目、经验等内容；`api/` 子目录暴露 `/api/contact`、`/api/github-stars` 等服务端端点，供前端页面在 Server Components 或客户端调用。三者通过路径契约协作——页面组件消费 API 路由返回的数据，共享同一份全局样式与主题配置，API 路由无状态且仅负责数据聚合。
