- 对外暴露的组件统一使用 `React.forwardRef` 并设置 `displayName`，便于调试与 DevTools 识别。
- className 拼接一律通过 `cn(...)` 合并，避免硬编码冲突。
- 组件变体通过 `cva` 声明 `variants` 与 `defaultVariants`，并以 `VariantProps<typeof xxx>` 推导 Props 类型。
- 对 Radix 原语采用“零逻辑薄封装”策略：仅追加默认样式与必要组合，行为完全委托给 Radix。
- 复合组件通过 `React.createContext` 在父子组件间传递上下文（如 FormFieldContext、FormItemContext），子组件通过自定义 hook（如 `useFormField`）读取。
- Toast 状态机使用常量 action types + reducer + 内存 listeners 数组实现，而非外部状态库。
