app/ 严格遵循 Next.js App Router 约定：顶层 layout.tsx、globals.css、manifest.ts、sitemap.ts 提供站点级 SEO、主题与 PWA；(root)/ 下按文件夹即路由组织博客、项目、经历、技能等内容展示页面并由其 layout.tsx 包裹；api/ 下通过 route.ts 暴露服务端接口（contact 转发 Google Form、notion-webhook 处理 Notion 回调）。内容页面与服务端 API 通过 Next.js 内置 fetch 与 NextResponse 通信，第三方服务地址与凭据集中从 @/config/site 与环境变量注入，使页面渲染、API 路由与站点元配置三者解耦但共享同一套配置来源。
