采用 Next.js App Router 的路由分组 `(root)`，所有页面共享 `layout.tsx` 提供的 MarketingLayout（包含 MainNav、GitHubStarBadge、ModeToggle、SiteFooter 以及 container 布局），通过 `@/config/routes` 注入导航项。
- 首页 `page.tsx` 作为聚合入口，按区块（projects/experience/contributions/skills/blogs/contact）组合各卡片组件，并通过 `ClientPageWrapper` 包裹客户端交互；同时注入 Person 与 SoftwareApplication 的 JSON-LD 结构化数据。
- 列表页（blogs、projects、experience、contributions、skills、resume、contact）统一使用 `PageContainer` 包装标题与描述，并从 `@/config/*` 配置文件中读取展示数据。
- 动态路由 `[slug]`（blogs）、`[expId]`（experience）、`[projectId]`（projects）通过 `generateStaticParams` + `get*` 函数实现预渲染，并在 `generateMetadata` 中生成 OpenGraph/Twitter Card SEO 元信息；未找到时调用 `notFound()`。
- 依赖方向单向：页面 → 共享 UI 组件（`@/components/common`、`@/components/ui`）→ 业务组件（`@/components/blogs|projects|experience|...`）→ 配置文件（`@/config/*`）与数据层（`@/lib/blogs`），不反向引用。
