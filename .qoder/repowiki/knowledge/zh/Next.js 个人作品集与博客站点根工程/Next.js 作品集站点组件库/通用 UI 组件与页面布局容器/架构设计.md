本模块是纯 React 客户端组件集合，按职责划分为四类：
- 页面结构容器：`page-container.tsx` 组合 `ClientPageWrapper`（带淡入上移动画）与 `PageHeader`，作为各页面的统一外层；`client-page-wrapper.tsx` 通过 motion 实现页面级入场动画。
- 导航与站点框架：`main-nav.tsx` 使用 next/navigation 的 `useSelectedLayoutSegment` 高亮当前段，并响应式折叠为 `mobile-nav.tsx`；`site-footer.tsx` 渲染来自 `@/config/socials` 的社交链接。
- 主题与模式：`theme-provider.tsx` 是对 `next-themes` 的薄封装，`mode-toggle.tsx` 提供明暗模式切换入口。
- 动画与交互：`animated-section.tsx`、`animated-text.tsx`、`scroll-animation.tsx`、`animated-link.tsx`、`animated-page-transition.tsx` 均基于 `motion/react` 封装滚动触发或过渡动画；`analytics.tsx` 提供分析埋点。
- 资源集中：`icons.tsx` 聚合 lucide-react、react-icons 及自定义 SVG，以命名空间对象 `Icons` 形式对外暴露，避免在业务组件中直接 import 多个图标库。
依赖方向单向向外：仅依赖 `@/config/*`、`@/lib/utils`、`@/components/ui/*`，不反向引用业务页面，保证可被任意页面复用。
