根目录通过 package.json 的 scripts（dev/build/start/lint）统一编排 Next.js 应用生命周期；next.config.js 集中声明 API 路由的 CORS 头（/api/sb-contact），作为 app_routes 中后端 API 的前置约束。tsconfig.json 配置 @/* 路径别名，使 app_routes、components、utilities、configuration、blog_content 等子模块之间可通过绝对路径互相引用，形成单一代码库内的分层协作：app_routes 负责页面与 API 挂载，components 提供 UI 原语与页面级卡片，configuration 集中静态数据，blog_content 提供 Markdown 源，utilities 提供 Zustand 全局状态与 Markdown 解析 Hook，所有子模块共享同一份依赖与构建产物。components.json 将 shadcn/ui 的组件与 utils 别名映射到 @/components 与 @/lib/utils，统一各子模块对 UI 原子组件的引入方式。
