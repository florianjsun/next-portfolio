- 需要 DOM 操作的组件统一以文件首行 `'use client'` 声明为客户端组件，服务端组件则省略该指令。
- 动画相关组件通过定义 variants 对象（initial/animate/whileInView）并使用 motion 包裹，配合 viewport.once 控制只播放一次。
- 图标统一从 `@/components/common/icons` 的 `Icons` 命名空间对象导入，而非在各组件中直接引入图标库。
- 样式类名通过 `cn()` 工具函数拼接，结合 Tailwind 响应式前缀（sm/md/lg）实现响应式布局。
- 组件接口使用独立 interface 定义 props 类型，并以解构方式接收参数，保持函数式组件签名清晰。
