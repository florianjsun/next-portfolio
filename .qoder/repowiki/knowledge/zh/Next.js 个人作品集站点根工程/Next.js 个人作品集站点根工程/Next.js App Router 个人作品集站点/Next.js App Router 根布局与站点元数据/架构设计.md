本模块是 Next.js App Router 的顶层入口，由四个职责清晰的文件组成：
- `app/layout.tsx` 作为根布局组件，通过导出 `metadata: Metadata` 对象集中声明站点 SEO（title/template/description/keywords/openGraph/twitter/robots/verification/icons），并在 `RootLayout` 中挂载 `ThemeProvider`、`ModalProvider`、`Analytics`、Convot 聊天小部件 Script，以及条件渲染的 Google Analytics。
- `app/globals.css` 基于 Tailwind v4（`@import "tailwindcss"` + `tw-animate-css`）构建，使用 `@theme inline` 暴露设计令牌（颜色、圆角、动画），在 `@layer base` 中以 `:root`、`.dark` 等类名覆盖 HSL 色值实现多主题，并提供 `.blog-content` Markdown 渲染样式。
- `app/manifest.ts` 导出符合 `MetadataRoute.Manifest` 的 PWA 清单，声明名称、start_url、display、主题色与图标。
- `app/sitemap.ts` 导出 `MetadataRoute.Sitemap`，静态列出主页及 skills/projects/experience/contributions/blogs/contact/resume 等路由，并通过 `getAllBlogsMeta()` 动态追加每篇博客条目。
依赖方向单向向下：layout 依赖 `@/config/site`、`@/components/*`、`@/providers/*`、`@/lib/fonts`、`@/lib/utils`；sitemap 仅依赖 `siteConfig` 与博客元数据读取器，不反向引用 layout。
