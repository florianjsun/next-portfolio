### Portfolio 模板
- 定义：本项目是一个基于 Next.js 16 的开源开发者个人作品集模板，用于展示技能、项目经历、时间线等内容，可快速 fork 并替换配置后部署为个人网站。
- 别名：minimal-next-portfolio、next-portfolio-template

### 路由组 (root)
- 定义：Next.js App Router 中使用 `(root)` 目录作为路由分组，所有页面路由（如 `/projects`、`/experience`、`/contact` 等）均位于该组下，便于统一布局与共享逻辑。
- 别名：(root) 路由组、root group

### 首页滚动模块
- 定义：首页 (`app/(root)/page.tsx`) 中以纵向滚动区块形式依次展示 Projects → Experience → Contributions → Skills → Blogs → Contact 各章节，每个区块通过锚点 id 与顶部导航菜单联动。
- 别名：首页区块、scroll sections

### Contact 模块
- 定义：首页底部的联系区块，复用 `/contact` 页面的 `ContactForm` 与 `GithubRedirectCard` 组件，采用双列布局（flex-col lg:flex-row），标题/描述取自 `pagesConfig.contact`。
- 别名：底部 Contact、contact section

### 主题系统
- 定义：基于 `next-themes` 实现的多主题切换，当前支持 light、dark、retro、cyberpunk、paper、aurora、synthwave 七套主题，通过 CSS 变量驱动颜色、圆角等样式 token。
- 别名：多主题、theme system

### 配置驱动架构
- 定义：站点内容（个人信息、项目、经验、技能、社交链接等）集中在 `config/` 目录下的 TypeScript 文件中，页面组件直接消费这些配置，无需数据库即可渲染完整站点。
- 别名：config-driven、静态配置

### 博客系统
- 定义：基于文件系统的 Markdown 博客，位于 `content/blogs/*.md`，通过 gray-matter 解析 frontmatter，remark + remark-gfm + remark-html 渲染为 HTML，再由 `lib/blogs.ts` 聚合。
- 别名：Markdown 博客、file-based blog

### shadcn/ui 组件库
- 定义：通过 `components.json` 配置的 shadcn/ui 组件集，底层基于 Radix UI 无头组件（accordion、dialog、dropdown-menu、tabs、toast、tooltip 等），配合 Tailwind 4 的 CSS-first 主题系统使用。
- 别名：shadcn、Radix 组件

### 动画系统
- 定义：结合 Motion（framer-motion 重命名为 motion）、tw-animate-css 以及自定义的 `AnimatedSection`、`ScrollAnimation` 等组件，实现滚动入场、淡入等交互动画。
- 别名：motion 动画、滚动动画
